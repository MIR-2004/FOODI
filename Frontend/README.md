# infood — Frontend Application

This folder contains the React frontend client for the **infood** application, powered by Vite, Tailwind CSS, DaisyUI, TanStack Query, and Firebase Auth.

For full-stack configuration and installation instructions (including Backend setup, Stripe setup, and database initialization), please refer to the main **[Root Readme.MD](../Readme.MD)** in the root workspace directory.

## 🛠️ Key Scripts

In the frontend directory, you can run:

### `npm run dev`
Runs the app in development mode at `http://localhost:5173`.

### `npm run build`
Builds the app for production to the `dist` folder. It correctly bundles React in production mode and optimizes the build for the best performance.

### `npm run lint`
Lints all Javascript & React files using ESLint.

### `npm run preview`
Locally previews the production build created by `npm run build`.
